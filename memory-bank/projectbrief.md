# Project Brief: Social Media Card Generator

**Goal:** Create a tool that generates social media cards (PNG format for X, LinkedIn, Instagram) based on user inputs (Team Name, Big Idea Headline, Looking For roles).

**Current Focus (v0.1.1):** Implement new visual requirements featuring a white background, red text (#FF2A2A), and a permanent "#LATAMACELERA" hashtag locked to the bottom-left corner within a dedicated 40px safe area.

**Core Component:** `CardCanvas` - responsible for rendering the card based on input props and theme settings.
